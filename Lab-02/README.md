# OOP Lab Submissions

## Step 1 — Clone the repository

Open a terminal and run this command. It will download the repo to your computer.

```
git clone <https://github.com/Zenhance/SWE-4202-24.git>
```

Then move into the folder it just created:

```
cd <SWE-4202-24>
```

---

## Step 2 — Set up your project folders

Inside the repo you will find a folder called `Lab-02`. Put your work there.

Your folder structure should look exactly like this:

```
Lab-02/
├── Problem-1-BankAccount/
│   └── BankAccount.java        ← your Java file (or BankAccount.cs for C#)
│
└── Problem-2-StackQueue/
    ├── StudentStack.java        ← (or .cs)
    └── StudentQueue.java        ← (or .cs)
```

Create those two folders yourself inside `Lab-02`. Do not rename them.

---

## Step 3 — Submit your work

Once your files are inside the correct folders, run these three commands one by one:

```
git add .
git commit -m "Lab 02 submission"
git push
```

That's it. Your work is now submitted.

---

## If you get stuck

- Make sure you are inside the repo folder before running any `git` command.
- If `git push` asks for a username and password, use your GitHub credentials.
- If a file is in the wrong folder, just move it and run the three commands above again.
